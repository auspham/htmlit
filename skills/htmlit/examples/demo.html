4. Discover the details

How does the self-reload work?

The daemon watches the file; on change the client fetches the new HTML and morphs the live DOM with Idiomorph - scroll, form state, and rendered diagrams survive.

What happens to my annotations?

Each note is pinned on its element as a numbered marker and queued as a pill; on Send they reach the agent with the element selector and a DOM snapshot.

Does it work with multiple artifacts?

Yes - one daemon serves many sessions keyed by file path, fully isolated from each other.
